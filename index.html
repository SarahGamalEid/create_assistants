QA AI Assistant Project

Each team is responsible for two AI assistants. Follow the structure below strictly.

Standard Structure (Required for All)

  • Assistant name & purpose | Target users | 3 Real use cases
  • Prompt Design: Must be structured (Role, Context, Task)
  • Demo: Sample Input + Sample Output
  • Evaluation: Accuracy, Time Saved, Risks

Team 1: Requirements Analysis Assistant

Assistant 1 (Bonus)

EVERYDAY USE

Build a simple assistant (e.g., Daily Planner, Meeting Summarizer, or Habit Tracker) that solves a real daily pain point. Show the "Before vs. After" impact.

Assistant 2 (Main Task)

QA CORE

Goal: Convert user stories into testable requirements.

  • Identify ambiguities in documentation.
  • Generate clear Acceptance Criteria.
  • Highlight potential logic risks.

Sample Input: User story for a login page.
